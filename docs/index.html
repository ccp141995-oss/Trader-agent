Connect Hyperliquid Account

Trading credentials are stored only in this browser's local storage. Nothing is sent anywhere except signed requests to Hyperliquid's own API.
Use an API / Agent wallet key (Hyperliquid app → Settings → API), not your main wallet's private key. Agent keys can trade but cannot withdraw or transfer funds — so a leak here can't drain your account. Start on Testnet.
Trade Agent — Research
Ranks every tradeable Hyperliquid perp by 24h volume, drops anything below your OI/volume floors, and scans only the top N that remain. This avoids wasting research calls — and avoids trading — on thin, easily-manipulated markets.
Trade Agent — Auto-scan & alerts
There is no scheduled "full scan" — Anthropic is only ever called when a coin actually trips a volume-spike or book-imbalance threshold. This checks free order-book/volume data every couple of minutes for free; the number above is just a cooldown floor between triggered scans, not a timer that forces one. If nothing trips a signal, nothing gets called, no matter how much time passes. Notifications only fire while this tab is open in your browser.
Trade Agent — Risk Rules
A stop-loss is required on every agent-sourced trade, and now it's bounded too: if the AI's stop (or one you type manually) sits farther from entry than the limit above, confirm is blocked until you tighten it or the size instead. Combined with max position size, this caps how much a single trade can lose. The default take-profit fills in automatically wherever a take-profit is left blank — on manual orders below and on agent recommendations that didn't suggest one — but you can always edit or clear it before confirming.
Sync to GitHub bot
This publishes watchlist/scan mode, filtered-universe thresholds, max position size, max leverage and default take-profit to docs/agent-config.json in your repo — the backend scanner and Telegram executor read it and use it in place of their GitHub Variable defaults. It never touches trading keys or funds. Scope the token to just this one repo with Contents read/write only.
