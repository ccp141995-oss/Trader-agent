Connect Hyperliquid Account

Trading credentials are stored only in this browser's local storage. Nothing is sent anywhere except signed requests to Hyperliquid's own API.
Use an API / Agent wallet key (Hyperliquid app → Settings → API), not your main wallet's private key. Agent keys can trade but cannot withdraw or transfer funds — so a leak here can't drain your account. Start on Testnet.
Trade Agent — Research
Technical checks (order book, volume, multi-timeframe alignment, support/resistance, chart patterns) always run for free, regardless of this toggle. Turn this off to run purely on technicals at zero API cost. Turn it on for AI-researched rationale — it now runs two independent passes and only keeps ideas that agree on both (self-consistency check), with no web search or sentiment involved.
When ON, every idea that clears your risk settings below executes automatically after a short window — Telegram gets a Cancel button instead of Confirm/Deny, and you'll still get the idea, the fill status, and any errors, just without a tap required. All of the same caps still apply (max position size, max leverage, max stop distance, max entry deviation, max take-profit distance) — this only removes the human-tap step, nothing else. Start with this OFF until you've watched the confirm-required flow work correctly for a while.
Ranks every tradeable Hyperliquid perp by 24h volume, drops anything below your OI/volume floors, and scans only the top N that remain. This avoids wasting research calls — and avoids trading — on thin, easily-manipulated markets.
Trade Agent — Auto-scan & alerts
Order-book and volume checks run every couple of minutes regardless of this setting — that part is always free and never throttled. The number above only throttles the Anthropic call specifically: if AI research is enabled and a signal trips again before this many minutes have passed since the last AI call, you'll get a technicals-only idea instead of waiting. With AI research turned off, this number does nothing — technicals-only ideas have no cooldown at all. Notifications only fire while this tab is open in your browser.
Trade Agent — Risk Rules
The AI sets entry, stop-loss, and take-profit prices from its own technical analysis — but every one of them is checked against the limits above before you ever see it, and again right before execution. A stop farther than your max distance gets replaced with a technical swing-based stop (or capped outright); a take-profit farther than its max gets capped the same way; an entry too far from the live market price gets replaced with the live price. Combined with max position size, this bounds how much a single trade can lose regardless of what the AI (or a stale price) suggests. The default take-profit fills in automatically wherever one is left blank — on manual orders below and on agent recommendations that didn't suggest one — but you can always edit or clear it before confirming.
Sync to GitHub bot
This publishes watchlist/scan mode, filtered-universe thresholds, max position size, max leverage and default take-profit to docs/agent-config.json in your repo — the backend scanner and Telegram executor read it and use it in place of their GitHub Variable defaults. It never touches trading keys or funds. Scope the token to just this one repo with Contents read/write only.
